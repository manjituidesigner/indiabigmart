# IndiaBigMart B2B Marketplace

India's premier modern B2B marketplace theme designed with clean **iOS / Apple aesthetics**, breathable spacing, and high-performance Tailwind CSS.

![IndiaBigMart Preview](https://images.unsplash.com/photo-1544717305-2782549b5136?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Key Features

- **Modern iOS Design System**:
  - Frosted glass header (`backdrop-blur-xl`) with sticky navigation
  - Ambient gradient containers with rounded-3xl cards and soft layered shadows
  - Inter & Plus Jakarta Sans typography
- **Trending on IndiaBigMart Showcase**:
  - 18 high-demand B2B products (Electric Scooter, Vastu Accessories, TMT Bars, CNC Lathes, etc.)
  - Real-time category filtering (All, Industrial, Consumer) and carousel pagination
- **Dynamic Vendor & Supplier Listing Page**:
  - Live transition from Home to Vendor Listing View
  - Exact Vastu Accessories products & verified suppliers from IndiaMART data
  - View switcher: **Grid View** (4 columns) & **List View** (horizontal cards with full specs)
  - Quick filter chips: City filters (Delhi, Mumbai, Indore, Kalyan, Hyderabad), Price filters, and TrustSEAL filters
  - Technical specifications table for each product
  - Verified supplier badges, Star ratings, response rate, and dual CTAs: **Contact Supplier** & **Call Now**
- **Interactive Procurement Modals**:
  - **"Get Best Price"** modal with prefilled product and vendor info
  - **"Post Requirement"** (RFQ) modal
  - Floating iOS dark frosted glass toast notifications
- **Buyer & Seller Services**:
  - "Pay with IndiaBigMart" (100% Escrow Protection)
  - "Start Selling on IndiaBigMart" seller onboarding card

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/manjituidesigner/indiabigmart.git

# Navigate to project folder
cd indiabigmart

# Start local server
npm start
# Server runs at http://localhost:3000
```

---

## ☁️ Deployment on Vercel

1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Other** / None (Static HTML).
3. Root Directory: `./`
4. Click **Deploy**!
